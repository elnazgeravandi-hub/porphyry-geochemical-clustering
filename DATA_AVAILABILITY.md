# Data availability

The original geochemical dataset is subject to data-owner restrictions, and the authors do not have permission to publish or redistribute it. Accordingly, the original sample records and restricted spatial inputs are not included in this repository. No commitment to provide these data on request is made.

This development repository provides a new implementation of specified computational procedures. Exact reproduction of the manuscript's numerical results requires authorized original inputs, matching configurations and verification of the computational environment. Such reproduction has not yet been established for this version.
