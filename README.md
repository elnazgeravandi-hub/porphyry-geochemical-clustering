# Porphyry Geochemical Clustering

Computational workflow accompanying the manuscript:

**Hybrid Clustering and Multi-Objective Evolutionary Optimization (MOPSO–NSGA-II) for Porphyry geochemical modeling and Mineral Prospectivity Enhancement**

## Repository status

This repository is being prepared to document the analysis workflow associated with the revised manuscript. Analysis scripts, configuration files, and execution instructions will be added as they are checked against the final implementation.

## Data access restrictions

The original geochemical dataset is subject to data-owner restrictions. The authors do not have permission to publish or redistribute these data; therefore, the original dataset is not included in this repository.

## Workflow scope

The workflow concerns six geochemical elements: Cu, Au, Mo, Bi, Pb, and Zn. It includes data preparation, censored-value treatment, compositional transformation, robust scaling, and baseline and optimized clustering using K-means, DBSCAN, and OPTICS with MOPSO and NSGA-II.

## Reproducibility

The completed repository will document input requirements, software dependencies, model parameters, optimization settings, and execution procedures. Exact reproduction of the manuscript’s numerical results requires authorized access to the original input data and the corresponding computational environment.
