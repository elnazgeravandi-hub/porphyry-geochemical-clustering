# راهنمای ساده بارگذاری

این بسته نسخهٔ توسعه‌ای است؛ هنوز نسخهٔ نهاییِ بازتولید نتایج مقاله نیست.

۱. فایل ZIP را روی کامپیوتر خود باز و Extract کنید.
۲. پوشهٔ porphyry-geochemical-clustering را باز کنید.
۳. وارد مخزن GitHub خود شوید.
۴. Add file و سپس Upload files را انتخاب کنید.
۵. محتویات داخل پوشه را به بخش بارگذاری بکشید؛ پوشهٔ مادر را به‌عنوان یک پوشهٔ اضافی بارگذاری نکنید.
۶. فایل README.md جدید جایگزین معرفی اولیه می‌شود و وضعیت واقعی توسعه را توضیح می‌دهد.
۷. متن Commit را بنویسید: Add development implementation and workflow documentation
۸. Commit changes را بزنید.

هیچ دادهٔ واقعی، خروجی مدل روی داده‌های اصلی، فایل GIS یا خروجی حاوی اطلاعات محرمانه را بارگذاری نکنید. در بارگذاری وب، وجود .gitignore تضمین نمی‌کند فایل انتخاب‌شده آپلود نشود؛ فایل‌ها را خودتان بررسی کنید.

برای اجرای محلی، دستورهای README انگلیسی را دنبال کنید. ورودی این نسخه باید غلظت‌های مثبت پس از آماده‌سازی تأییدشده باشد. فایل داده را فقط در private_data روی کامپیوتر خود نگه دارید.

قبل از معرفی نسخهٔ نهایی به سردبیر: تکمیل ReX-CoDA، اجرای تنظیمات کامل روی داده‌های مجاز، تطبیق جدول‌ها و شکل‌ها، و ثبت نسخهٔ نهایی لازم است.
