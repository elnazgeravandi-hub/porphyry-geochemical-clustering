# بارگذاری مرحله‌ای نسخهٔ مبتنی بر مقاله

این بسته کامل است. نسخهٔ جدید تصحیح سانسور مستقل از نوت‌بوک نوشته شده؛ کدهای اصلی خوشه‌بندی که از متد نوشته شده بودند حفظ و بهبود یافته‌اند.

۱. ZIP را Extract کنید و داخل پوشهٔ porphyry-geochemical-clustering بروید.
۲. pyproject.toml و requirements.txt را از Add file → Upload files بارگذاری کنید؛ فایل همنام به‌روزرسانی می‌شود.
۳. خود پوشهٔ src را روی صفحه بکشید تا مسیر src/porphyry حفظ شود.
۴. خود پوشهٔ configs را بارگذاری کنید.
۵. خود پوشهٔ tests را بارگذاری کنید.
۶. فایل‌های جدید docs را بارگذاری کنید. پوشهٔ docs قدیمی ممکن است فایل‌های منسوخ داشته باشد؛ فهرست آن‌ها در legacy_docs_to_remove.txt آمده است. حذف فقط همین مستندات منسوخ انجام شود.
۷. README.md و در صورت نیاز DATA_AVAILABILITY.md را به‌روزرسانی کنید. متن محدودیت داده در نسخهٔ جدید همان بیانیهٔ کوتاه و روشن است.

داده‌ها، فایل‌های GIS و خروجی‌های نوت‌بوک را انتخاب نکنید. بارگذاری وب تابع محافظت انتخاب فایل .gitignore نیست.

این نسخه ادعای بازتولید اعداد مقاله ندارد؛ باید روی ورودی اصلیِ مجاز اجرا شود. جزئیات اجرایی تکمیلی تصحیح سانسور در مستندات ثبت شده‌اند و نیاز به تطبیق/توضیح در متد دارند.
